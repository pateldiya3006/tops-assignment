SDLC Assignment

1. List all 6 phases of SDLC in order with one line about each.

  1. Requirement Analysis: Gather and understand the project requirements from the client.
  2. System Design: Create the architecture and design of the software.
  3. Development: Write the source code based on the design.
  4. Testing: Test the software to find and fix bugs.
  5. Deployment: Release the software to users.
  6. Maintenance: Update the software and fix issues after deployment.

2. Write 3 differences between Agile and Waterfall models.

Agile Waterfall
Development is done in small iterations. Development follows a fixed sequence of phases.
Changes can be made at any stage. Changes are difficult after a phase is completed.
Customer feedback is taken regularly. Customer feedback is usually taken at the end.

3. Name the 3 main Scrum roles and write one line about the responsibility of each.

  • Product Owner: Defines project requirements and manages the product backlog.
  • Scrum Master: Guides the Scrum team and removes obstacles during development.
  • Development Team: Designs, develops, and tests the software.

4. What is a Sprint in Scrum? Mention its typical duration.

Sprint: A Sprint is a fixed time period during which the Scrum team completes a set of tasks.

Typical Duration: 1 to 4 weeks (commonly 2 weeks).

5. What do these Jira board columns mean?

  • Backlog: List of tasks that are planned but not yet started.
  • To Do: Tasks that are ready to begin.
  • In Progress: Tasks that are currently being worked on.
  • Done: Tasks that have been completed successfully.
