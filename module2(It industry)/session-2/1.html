Software Architecture Assignment

1. What are the three main layers of software architecture?

  1. Presentation Layer: Displays information to the user and accepts user input.
  2. Business Logic Layer: Processes data and applies business rules.
  3. Data Layer: Stores, retrieves, and manages data in the database.

2. Define Client and Server with one real-life example.

Client: A client is a device or application that sends a request for information or services.

Server: A server is a computer or system that receives requests and provides the required data or services.

Example: When you open YouTube on your phone, your phone acts as the client, and the YouTube server sends videos to your phone.

3. Write 2 differences each between Desktop Apps, Web Apps, and Mobile Apps.

Desktop Apps

  • Installed on a computer or laptop.
  • Can work without an internet connection.

Web Apps

  • Run inside a web browser.
  • Usually require an internet connection.

Mobile Apps

  • Installed on smartphones or tablets.
  • Designed for touch-screen devices.
